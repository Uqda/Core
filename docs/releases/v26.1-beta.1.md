# Uqda 26.1 Beta 1

Uqda 26.1 Beta 1 is a prerelease for testing. It makes a private encrypted network something anyone can set up in a
few minutes, and closes the main security gaps inherited from the original
implementation. It stays fully compatible with the Yggdrasil network.

> **Experimental project.** Uqda is under active development. It is tested
> extensively but has not had an independent security audit. Do not rely on it
> where a failure would put people or critical systems at risk.

## New

- **One-command setup.** `sudo uqda setup country=germany` creates (or keeps)
  the node identity, a private network with a random 192-bit group password,
  the inbound firewall, and the two fastest healthy public peers in that
  country. On an existing node it changes nothing it does not need to.
- **Invites.** `sudo uqda invite` shows a one-time invite as text and as a QR
  code; `sudo uqda join INVITE` adds the new device. The invite contains no
  password: the new device checks the inviting node's identity over TLS 1.3,
  proves it holds the invite's random secret, and only then receives the group
  password and peers. Invites expire (15 minutes by default) and are
  rate-limited.
- **Inbound firewall.** Unsolicited traffic arriving over Uqda is dropped
  unless a rule allows it by device key, address, protocol and port. Replies to
  your own connections, ping and network error messages always work. It is on
  for new nodes; existing configurations keep it off and `uqda status` explains
  how to turn it on. `uqda firewall` shows rules and counters.
- **Replay-proof handshake.** Uqda nodes prove they hold their key on every new
  connection, so a recorded handshake can no longer be replayed to impersonate
  a peer or get past `AllowedPublicKeys`. `RequireFreshHandshake` enforces it
  in all-Uqda networks. Yggdrasil peers are unaffected.
- **Connection-flood limits.** At most 256 pending handshakes per node and 8
  per source. The admin API is limited to 64 connections, 1 MiB requests and a
  five-minute idle time.

## Fixed

- `uqda setup` and `uqda join` keep the configuration file's owner and group,
  so the service account can still read it.
- Lint is fixed for Go 1.27. CI works on private and public repositories, and
  workflow artifacts expire after 14 days.

## Install or update

The Linux quick installer selects the newest release, including this
prerelease. Use the stable 26.0.5 packages if you need a stable release.


| System | Install | Update |
|---|---|---|
| Linux (systemd) | `curl -fsSLo uqda-install.sh https://raw.githubusercontent.com/Uqda/Core/main/contrib/install/linux.sh && sudo sh uqda-install.sh install` | same script, `sudo sh uqda-install.sh update` |
| macOS | the `.pkg` for your Mac below (Homebrew stays on the stable release until 26.1 is final) | install the newer `.pkg` |
| Windows | the `.msi` for your system below | install the newer `.msi` |
| Debian / Ubuntu | `sudo apt install ./uqda-26.1-beta.1-ARCH.deb` | the same with the newer file |

Then run `sudo uqda setup country=NAME` on a new node. Updates keep your
identity and configuration. Verify downloads against `SHA256SUMS`.

## Compatibility

- Peering, routing and sessions with Yggdrasil and earlier Uqda releases are
  unchanged; this is checked against the official Yggdrasil implementation.
- The new handshake field is optional and ignored by nodes that do not know it.
- Private groups created before 26.0.2 still need the coordinated upgrade
  described in the 26.0.2 notes.

## Known limits

- Connections between nodes go through peer nodes rather than directly through
  NAT, so some paths are slower than with Tailscale or ZeroTier.
- On Umbrel the firewall stays off until the dashboard can manage its rules.
- The Android and Apple artifacts are SDKs for app developers, not ready-made
  phone apps.
- Installers are unsigned. Uqda does not provide anonymity.
