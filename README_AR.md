# نواة عُقَد

**شبكة متراكبة مشفّرة وذاتية التنظيم تعمل ببروتوكول الإنترنت الإصدار السادس (IPv6)**

[الإنجليزية](README.md) · **العربية**

> اسم **عُقَد (UQDA)** مأخوذ من الكلمة العربية «عُقَد»، أي العُقد والروابط التي تكوّن الشبكة. يهدف المشروع إلى إنشاء شبكات مشفّرة تعمل ببروتوكول الإنترنت الإصدار السادس (IPv6) فوق اتصالات الإصدار الرابع (IPv4) أو الإصدار السادس الموجودة مسبقًا.

## حالة المشروع

**أحدث إصدار مستقر من عُقَد هو الموصى به للأنظمة المدعومة.** لم يخضع المشروع حتى الآن لتدقيق أمني مستقل وشامل، ولا يهدف إلى إخفاء الهوية؛ فقد يتمكن النظير المتصل مباشرة من معرفة عنوان بروتوكول الإنترنت (IP) الحقيقي للاتصال. لذلك يُنصح باستخدام جدار حماية يدعم الإصدار السادس وعدم كشف أي خدمة لا تريد إتاحتها لبقية المشاركين في الشبكة.

راجع [الدليل الإنجليزي الشامل للمشروع](docs/PROJECT_GUIDE.md) لشرح المعمارية،
والهوية والعناوين، والتوجيه والتشفير، وحدود الأمان، والإعداد والتثبيت على كل
نظام، والتشغيل والتطوير.

لتشغيل عُقَد مرة واحدة على راوتر أو قطعة منزلية وخدمة كل الهواتف والأجهزة دون
تثبيت البرنامج عليها، راجع [دليل بوابة عُقَد المنزلية](docs/HOME_GATEWAY.md)
لـ Raspberry Pi OS وDebian/Ubuntu وملف OpenWrt التجريبي.
ولشبكات الزوار العامة، استخدم [ملف بوابة المقهى المحصّن](docs/CAFE_GATEWAY.md).
ولقياس زمن الاستجابة p95 واختيار النظراء وتشخيص ازدحام الطوابير، راجع
[دليل الأداء](docs/PERFORMANCE.md).

## المزايا

- تشفير حركة البيانات بين عُقد الشبكة من طرف إلى طرف.
- توجيه ذاتي التنظيم ومتعدد القفزات دون سلطة توجيه مركزية.
- اشتقاق عنوان الإصدار السادس من الهوية التشفيرية للعقدة.
- الاتصال بين النظراء عبر بروتوكول التحكم بالنقل (TCP)، وأمن طبقة النقل (TLS)، وبروتوكول النقل السريع (QUIC)، ومقبس الويب (WebSocket)، ومقبس الويب الآمن (WSS)، وبروتوكول المقابس (SOCKS)، ومقابس يونكس (Unix sockets).
- اكتشاف محلي اختياري للعُقد بواسطة البث المتعدد (multicast).
- واجهة شبكة افتراضية (TUN) تتيح لتطبيقات الإصدار السادس العادية استخدام الشبكة.
- دعم وتكاملات لأنظمة لينكس (Linux)، وماك أو إس (macOS)، وويندوز (Windows)، وفري بي إس دي (FreeBSD)، وأوبن بي إس دي (OpenBSD)، وأوبن دبليو آر تي (OpenWrt)، إضافة إلى إيدج راوتر (EdgeRouter) وفاي أو إس (VyOS).
- إدارة محلية بواسطة أداة `uqdactl`.

## آلية العمل

تنشئ كل عقدة هوية تشفيرية وتشتق عنوان الإصدار السادس من مفتاحها العام. ينشئ البرنامج واجهة شبكة افتراضية (TUN)، ثم يتصل بالنظراء المحددين في الإعدادات أو المكتشفين على الشبكة المحلية، ويوجّه الحزم المشفّرة عبر المسارات المتاحة. ويمكن إنشاء روابط النظراء فوق شبكات الإصدار الرابع أو الإصدار السادس.

## البناء من الشفرة المصدرية

المتطلبات: [لغة غو (Go) بالإصدار 1.25.13 أو أحدث](https://go.dev/dl/)، ونظام إدارة الإصدارات غِت (Git).

</div>

```bash
git clone https://github.com/Uqda/Core.git
cd Core
./build
```

<div dir="rtl" align="right">

ينتج عن البناء ملفان تنفيذيان:

- `uqda` — برنامج تشغيل عقدة الشبكة؛
- `uqdactl` — أداة الإدارة المحلية.

## التثبيت المتحقق منه بأمر واحد

يتعرّف برنامج التثبيت على نظام التشغيل ونوع المعالج، ويختار الحزمة الأصلية
المناسبة عند توفرها، ثم يتحقق من بصمتها الرقمية بخوارزمية شا-256 (SHA-256)
قبل تثبيتها بمدير الحزم الخاص بالنظام. كما تنشر الإصدارات المستقرة حزمة توقيع
Sigstore لملف البصمات وإثباتات مصدر للملفات المنشورة. راجع البرنامج النصي قبل تشغيله:

</div>

```bash
curl -fsSLO https://github.com/Uqda/Core/releases/latest/download/install.sh
sudo sh install.sh
```

<div dir="rtl" align="right">

### التثبيت بواسطة Homebrew على macOS

يوفر المستودع أيضًا حزمة Homebrew Cask تشغّل برنامج التثبيت المتحقق منه نفسه،
وتدعم أجهزة Apple Silicon وIntel:

</div>

```bash
brew tap uqda/core https://github.com/Uqda/Core
brew trust --cask uqda/core/uqda
brew install --cask uqda/core/uqda
```

<div dir="rtl" align="right">

ولجعل Homebrew يبحث عن أحدث إصدار مستقر ويثبّته:

</div>

```bash
brew upgrade --cask --greedy-latest uqda
```

<div dir="rtl" align="right">

يتطلب Homebrew موافقة صريحة على مستودعات الطرف الثالث. يقيّد أمر الثقة
الموضح أعلاه الموافقة بحزمة `uqda/core/uqda` وحدها بدل الوثوق بكل التعريفات
التنفيذية في المستودع. ويفوّض Homebrew اختيار حزمة المعالج والتحقق من SHA-256
إلى برنامج التثبيت؛ لذلك تستخدم طريقة Homebrew والطريقة المباشرة الحماية نفسها.

وللتحديث عبر المسار المتحقق منه نفسه مع الاحتفاظ بملف الإعداد وهوية العقدة الحالية:

</div>

```bash
curl -fsSLO https://github.com/Uqda/Core/releases/latest/download/updater.sh
sudo sh updater.sh
```

<div dir="rtl" align="right">

للتحقق من هوية ناشر الإصدار بواسطة Sigstore قبل التثبيت، راجع
[دليل التحقق من الإصدارات](docs/release-verification.md).

تشمل مسارات الإصدار المدعومة أنظمة ديبيان وأوبونتو وفيدورا، وأنظمة فيدورا
الثابتة مثل بازايت (Bazzite)، والمعتمدة على مدير الخدمات سيستم دي (systemd)،
إضافة إلى ماك أو إس (macOS)، وإيدج أو إس 2 (EdgeOS 2.x)، وفاي أو إس
1.3 (VyOS 1.3)، إضافة إلى الأنظمة المحمولة المدرجة من لينكس وفري بي إس دي
وأوبن بي إس دي. أما مستخدمو ويندوز فعليهم تنزيل ملف التثبيت المناسب بامتداد
`.msi` من صفحة الإصدار. لا يشمل برنامج التثبيت بأمر واحد نظام أوبن دبليو آر تي
(OpenWrt)، وما زال هذا الهدف غير معتمد باختبار تشغيل فعلي في الإصدار `v0.1.1`.

لا يملك المشروع حاليًا حساب Apple Developer مدفوعًا، ولذلك تحمل حزم ماك
اللاحقة `-unsigned.pkg` في اسمها، وسيعرض Finder تحذير Gatekeeper عند فتحها.
يُفضّل استخدام برنامج التثبيت المتحقق منه بالأعلى؛ إذ يتحقق من بصمة SHA-256
قبل تشغيل مثبّت النظام. لا تعطّل Gatekeeper على مستوى النظام.

## التشغيل

لتشغيل عقدة مؤقتة بإعدادات ومفاتيح تُنشأ تلقائيًا:

</div>

```bash
sudo ./uqda -autoconf
```

<div dir="rtl" align="right">

لإنشاء إعدادات دائمة ومراجعتها قبل التشغيل:

</div>

```bash
./uqda -genconf > uqda.conf
$EDITOR uqda.conf
sudo ./uqda -useconffile ./uqda.conf
```

<div dir="rtl" align="right">

تُحصر إدارة العقدة في الأنظمة الشبيهة بيونكس بالمستخدم الجذر. لذلك يجب تشغيل
جميع أوامر أداة التحكّم `uqdactl` بواسطة `sudo`، مثل
`sudo uqdactl getSelf`. يُنشأ مقبس الإدارة المحلي بصلاحية `0600`، ولا يُمنح
المستخدمون العاديون أو المجموعات حق الوصول إليه.

تبقى العقد الجديدة متوافقة مع العقد القديمة التي تستخدم إصدار البروتوكول `0.5`. وعندما يدعم الطرفان المصافحة الأمنية المحسّنة، يفعّلانها تلقائيًا. ولإلزام رابط مُدار باستخدام المصافحة المحسّنة ورفض العقد القديمة، أضف الخيار `?secure=required` إلى عنوان النظير وعنوان الاستماع على الطرفين.

يمكن إضافة الخيار `-json` إلى أمر إنشاء الإعدادات للحصول على تنسيق جيسون (JSON) بدل تنسيق جيسون البشري المشروح (HJSON). يحتاج إنشاء واجهة الشبكة الافتراضية عادةً إلى صلاحيات المدير. وفي نظام لينكس يمكن منح البرنامج قدرة إدارة الشبكة المطلوبة بدل تشغيله كاملًا بصلاحيات المستخدم الجذر (root):

</div>

```bash
sudo setcap CAP_NET_ADMIN=+eip ./uqda
./uqda -useconffile ./uqda.conf
```

<div dir="rtl" align="right">

## التشغيل بواسطة الحاويات

يمكن بناء المشروع وتشغيله بواسطة دوكر (Docker):

</div>

```bash
docker build -t uqda-core -f contrib/docker/Dockerfile .
docker run --rm -it \
  --cap-add=NET_ADMIN \
  --device=/dev/net/tun \
  -v uqda-config:/etc/uqda \
  uqda-core
```

<div dir="rtl" align="right">

تنشئ الحاوية إعداداتها داخل وحدة التخزين الدائمة `uqda-config` عند التشغيل الأول.

## إيدج أو إس وفاي أو إس

ينتج مسار الحزم الآلي حزم راوتر متكاملة لإيدج راوتر إكس (`mipsel`)، وإيدج راوتر لايت (`mips`)، وفاي أو إس (`amd64` و`i386`). بعد تثبيت حزمة ديبيان (`.deb`) المناسبة، أنشئ واجهة عُقَد من سطر أوامر الراوتر الأصلي:

</div>

```text
configure
set interfaces uqda tun0
set interfaces uqda tun0 description UQDA
commit
save
```

<div dir="rtl" align="right">

لكل واجهة ملف إعداد مستقل باسم `/config/uqda.tunN.conf`، ومقبس إدارة مستقل، وخدمة مستقلة باسم `uqda@tunN.service`. يمكن تعديل إعدادات النظراء المتقدمة في ذلك الملف، ثم تطبيقها بالأمر `restart uqda tun0`. راجع مجلد [`contrib/vyatta`](contrib/vyatta) لمعرفة الأنظمة المدعومة وأوامر بناء الحزم محليًا.

## بنية المستودع

| المسار | الغرض |
| --- | --- |
| `cmd/uqda` | نقطة بدء برنامج تشغيل العقدة |
| `cmd/uqdactl` | أداة الإدارة المحلية |
| `src/core` | الجلسات والتوجيه ووسائط الاتصال بين النظراء |
| `src/config` | الإعدادات والقيم الافتراضية الخاصة بالأنظمة |
| `src/tun` | واجهات الشبكة الافتراضية الخاصة بكل نظام |
| `src/admin` | واجهة الإدارة المحلية |
| `contrib/` | الحاويات وملفات الخدمات والحزم وتكاملات الأنظمة |
| `.github/workflows/` | البناء والاختبارات والتغليف الآلي |
