# عُقدة · Uqda

[English](README.md) · [كيف تعمل](docs/how-it-works.md) · [ابنِ على عُقدة](docs/build-on-uqda.md) · [التوثيق](docs/README.md) · [الإصدارات](https://github.com/Uqda/Core/releases)

**عُقدة شبكة عالمية مشفّرة، مكوّنة من أجهزة مستخدميها فقط.**

اسمها يشرح فكرتها: كل جهاز يثبّت عُقدة يصبح **عُقدة** في الشبكة. يحصل على عنوان
مشفّر دائم، ويتصل بالعُقد القريبة منه، ويساهم في نقل حركة الشبكة. لا توجد شركة في
المنتصف، ولا حساب تنشئه، ولا خادم يمكن إيقافه. الشبكة هي مستخدموها، وتكبر مع كل
من ينضم إليها.

> **مشروع تجريبي.** تخضع عُقدة لاختبارات واسعة، لكنها لم تخضع بعدُ لتدقيق أمني
> مستقل. لا تعتمد عليها حيث يعرّض تعطّلها الأشخاص أو الأنظمة الحساسة للخطر.

## شبكة تبني نفسها

<div dir="ltr">

```
        your phone ─── your laptop ─── your home server
                            │                 │
              (same Wi-Fi, no internet)    internet
                                              │
   a friend's PC ─── public node ─── public node ─── a server abroad
```

</div>

1. **ثبّتها فتصبح عُقدة.** يولّد جهازك زوج مفاتيح خاصًا به، وعنوان IPv6 محسوبًا منه
   مثل `200:1a2b:3c4d::7`. لا تمنحه أي جهة، ولا يستطيع غيرك استخدامه.
2. **العُقد تجد بعضها.** تتصل عُقدة تلقائيًا بالعُقد القريبة على شبكتك المحلية،
   وبعُقد عامة سريعة على الإنترنت.
3. **كل عُقدة تنقل الحركة.** تنتقل البيانات من عُقدة إلى أخرى حتى تصل، مشفّرة من
   طرف إلى طرف. العُقد في المنتصف تمرّر ما لا تستطيع قراءته.
4. **الشبكة تكبر.** كل عُقدة جديدة طريق إضافي للجميع.

تعمل عُقدة داخل شبكة [Yggdrasil](https://yggdrasil-network.github.io/) العالمية
القائمة وتتحدث بروتوكولها، فتنضم كل عُقدة جديدة إلى آلاف العُقد الموجودة من اليوم
الأول: شبكة عالمية داخل الإنترنت العالمي. يشرح دليل [كيف تعمل](docs/how-it-works.md)
الهوية والتوجيه والتشفير بالتفصيل.

## لماذا تستخدمها؟

| | عُقدة | خدمات VPN والشبكات المعتادة |
|---|---|---|
| من يدير الشبكة | عُقد مستخدميها | شركة |
| الحساب | لا يوجد | مطلوب |
| هل يمكن إيقافها أو حجب خادمها أو رفع سعرها؟ | لا يوجد خادم مركزي لذلك | نعم |
| تعمل بين الأجهزة دون إنترنت | نعم، على الشبكة المحلية | غالبًا لا |
| الوصول لجهاز خلف NAT دون فتح منافذ | نعم | نعم |
| إضافة جهاز | `uqda invite` ثم `uqda join` | تسجيل الدخول لدى الشركة |
| من يصل إلى خدماتك | جدار ناري مدمج بقواعد حسب مفتاح الجهاز | لوحة تحكم الشركة |

ما يتفوّق فيه الآخرون حاليًا: يفتحون مسارات مباشرة عبر NAT، بينما تمر حركة عُقدة
أحيانًا عبر عُقد أخرى.

## نوعان من الشبكات، بنية واحدة

- **مجموعة خاصة:** لا يتواصل معك إلا من يشاركك سرّ المجموعة، حتى وإن نقلت العُقد
  العامة حركتكم المشفّرة. لأجهزتك أو عائلتك أو فريقك، وهي الخيار الافتراضي.
- **الشبكة العامة:** تصل إلى أي عُقدة في العالم ويصل إليك أي منها، ويقرّر الجدار
  الناري ما هو مفتوح. للخدمات التي تريد أن يستخدمها الجميع.

راجع [الشبكات](docs/networks.md).

## ابدأ بثلاثة أوامر

ثبّت البرنامج لنظامك ([كل الخيارات](docs/installation.md)):

| النظام | التثبيت |
|---|---|
| Linux | `curl -fsSLo uqda-install.sh https://raw.githubusercontent.com/Uqda/Core/main/contrib/install/linux.sh && sudo sh uqda-install.sh install` |
| macOS | `brew install --cask Uqda/tap/uqda` |
| Windows | ملف `.msi` المناسب لجهازك من [الإصدارات](https://github.com/Uqda/Core/releases) |
| Debian / Ubuntu | ملف `.deb` من [الإصدارات](https://github.com/Uqda/Core/releases) |
| Umbrel | المتجر المجتمعي `https://github.com/Uqda/umbrel-app-store` ← **Uqda Network** |

ثم:

<div dir="ltr">

```sh
sudo uqda setup country=germany   # identity, private network, firewall, fast peers kept healthy
sudo systemctl restart uqda       # setup prints the right command for your system
sudo uqda invite                  # on each new device: sudo uqda join <invite>
```

</div>

- الأمر الأول ينشئ هويتك وشبكة خاصة، ويفعّل الجدار الناري، ويختار عُقدًا عامة
  سريعة ويحافظ عليها سليمة تلقائيًا.
- الأمر الثاني يعيد تشغيل الخدمة، ويطبع `setup` الأمر المناسب لنظامك.
- الأمر الثالث يصدر دعوة. نفّذ `uqda join` بها على كل جهاز جديد.

يعرض `uqda find` الدول المتاحة. والشرح الكامل، بما فيه كيف تصل إلى خدمة على
جهاز آخر، في دليل [البدء](docs/getting-started.md).

## ابنِ على عُقدة

تعطي عُقدة كل جهاز عنوانًا يثبت هويته، والباقي لك: مواقع، ودردشة، ومشاركة ملفات،
وألعاب، وأدوات، وتحكّم بالبيت الذكي، وتطبيقات. **أي برنامج يستمع على IPv6 يعمل على
عُقدة مباشرة.**

<div dir="ltr">

```sh
python3 -m http.server 8080 --bind ::      # then open http://[your-address]:8080/
```

</div>

يشرح دليل [ابنِ على عُقدة](docs/build-on-uqda.md) استضافة المواقع، واستخدام
العنوان كهوية، وواجهة الإدارة للأدوات، ومكتبات تطبيقات الهاتف.

## الأوامر اليومية

| الأمر | ماذا يفعل |
|---|---|
| `uqda status` | فحص الحالة مع طريقة إصلاح كل تحذير |
| `uqda info` | عنوانك ومفتاحك العام |
| `uqda peers` | اتصالات عُقدتك وحركة البيانات وزمن الاستجابة |
| `uqda autopeers` | العُقد العامة التي يحافظ عليها البرنامج تلقائيًا |
| `uqda firewall` | قواعد الجدار الناري والحزم المحجوبة |
| `uqda test ADDRESS` | اختبار الوصول وفقد الحزم إلى عُقدة أخرى |
| `uqda help COMMAND` | شرح أي أمر |

## الأمان باختصار

- **الهوية:** مفاتيح Ed25519، والعنوان مشتق من المفتاح ولا يمكن انتحاله دونه.
- **التشفير:** الجلسات بـ X25519 وXSalsa20-Poly1305 بمفاتيح مؤقتة متجددة، تحمي
  الحركة القديمة إن تسرّب مفتاح لاحقًا وترفض إعادة إرسال الحزم. العُقد الوسيطة تنقل
  ولا تقرأ.
- **المجموعات الخاصة:** يُقوّى سرّ المجموعة بـ Argon2id، ولا يستطيع الغرباء فتح جلسات
  مع أعضائها.
- **الجدار الناري:** مفعّل افتراضيًا للأجهزة الجديدة، ولا يدخل إلا الرد على اتصالاتك
  والخدمات التي تسمح بها.
- **المصافحة:** تثبت عُقد عُقدة مفاتيحها في كل اتصال، فلا يمكن إعادة إرسال مصافحة
  مسجّلة، وتُحدّ موجات الاتصالات.
- **الدعوات:** لمرة واحدة وتنتهي صلاحيتها، ويُتحقق منها عبر TLS 1.3 بمفتاح الجهاز
  الداعي.

عُقدة **لا** توفّر إخفاء الهوية، وواجهة الإدارة محلية ودون مصادقة. راجع
[نموذج الأمان](docs/security.md)، وأبلغ عن الثغرات بسرية وفق [SECURITY](SECURITY.md).
