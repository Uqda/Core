# عُقدة

[English](README.md)

**عُقدة (Uqda Core) برنامج شبكي مستقل الصيانة، متوافق مع شبكة Yggdrasil
القائمة، ويضم تحسينات في الأمان والموثوقية وسهولة التشغيل.** يوفّر اتصال IPv6
مشفّرًا بين العُقد، ويمكنه ربط الأقران عبر IPv4 أو IPv6.

**الإصدار الحالي: عُقدة 26.0.2 (`v26.0.2`).** الإصدار متاح للاستخدام والاختبار العام.
إذا واجهت مشكلة، أبلغ عنها عبر
[نموذج البلاغ](https://github.com/Uqda/Core/issues/new?template=bug_report.yml).
راجع [سجل الإصدارات](CHANGELOG.md) لمعرفة نطاق الاختبارات والقيود المعروفة.

المشروع مشتق من تنفيذ Yggdrasil المفتوح المصدر، ولا ينشئ شبكة منفصلة ولا يمثّل
تأييدًا رسميًا من مطوّري المشروع الأصلي. اسم عُقدة يشير إلى نقطة اتصال في الشبكة،
وقد تشارك في تمرير البيانات بين العُقد؛ أما Uqda فليس اختصارًا لعبارة.

## ما الذي يوفّره؟

- عناوين IPv6 مشتقة من المفاتيح العامة وجلسات مشفّرة من طرف إلى طرف.
- اتصالات أقران عبر TCP وTLS وQUIC وWebSocket وSOCKS ومقابس Unix.
- اكتشاف محلي للأقران، وتكامل مع واجهة TUN، وإدارة محلية بواسطة `uqdactl`.
- فحص سريع لحالة العقدة بأمر `uqdactl doctor` أو `uqdactl status`.
- اختبار وصول العقدة الأخرى وفقد الحزم بأمر `uqdactl test <عنوان IPv6>`.
- فحص الإعدادات قبل التشغيل، وتحذيرات بشأن صلاحيات ملفات المفاتيح على Unix
  وإتاحة واجهة الإدارة خارج الجهاز، وتأخيرات متنوّعة عند إعادة الاتصال.

يعتمد التوجيه وتشفير الجلسات على Ironwood. التوافق مع Yggdrasil مطلب أساسي؛
ويتضمن المستودع اختبار توافق مع إصدار مثبّت من التنفيذ الأصلي، يُبنى بصورة
مستقلة، لفحص اتصال الأقران ونقل حزم IPv6 وإعادة الاتصال والعبور عبر عقدة وسيطة.

## استخدام خدمات Umbrel عبر عقدة

الفائدة العملية هي الوصول إلى خدمة موجودة، مثل ملفاتك أو SSH، عبر اتصال IPv6
مشفّر بين جهاز Umbrel وجهاز آخر متصل بعقدة. يجب تجهيز استماع الخدمة على IPv6
وتسجيل الدخول وجدارها الناري. اتصال عقدة أخرى وحده لا يثبت أن التطبيق متاح،
ولا تُنشر التطبيقات تلقائيًا. فتح لوحة الإدارة على الهاتف لا يربطه بالشبكة.
راجع [دليل الوصول للخدمات على Umbrel](docs/umbrel.md#your-services-over-uqda)
لخطوات الإعداد المقصود وحالة تطوير دليل عناوين الخدمات الجديد.
وللوصول إلى واجهة Umbrel وبوابات تطبيقاته الموجودة، راجع
[مسار الوصول الخاص والقيود](docs/umbrel-remote-access.md).

## البناء والتشغيل

تتضمن عُقدة واجهة أوامر مختصرة: `uqda` لعرض الحالة،
و`uqda peers` للأقران، و`uqda info` للهوية، و`uqda test <IPv6>` للاختبار.
وتبقى أوامر `uqdactl` أدناه متاحة للإدارة المتقدمة.
راجع [دليل الأوامر](docs/commands.md).

ثبّت Go 1.25 أو أحدث، ثم نفّذ:

```sh
git clone https://github.com/Uqda/Core.git
cd Core
./build
./uqda --version
./uqdactl version
```

على Windows استخدم `build.bat`. ينتج البناء البرنامجين `uqda` و`uqdactl`.
توجد أدوات التحزيم للمنصات المختلفة في `contrib/`، ويجب اختبار الحزم على أنظمتها
قبل توزيعها. راجع [دليل التثبيت](docs/installation.md).

لإنشاء **عقدة جديدة**، ولّد ملف الإعدادات مرة واحدة واحمِه:

```sh
umask 077
./uqda -genconf > uqda.conf
./uqda -useconffile uqda.conf -checkconf
./uqda -useconffile uqda.conf
```

لا تستبدل ملفًا موجودًا بهذا الأمر؛ فالملف يحتفظ بهوية العقدة. أضف عناوين أقران
موثوقين إلى `Peers` أو استخدم الاكتشاف المحلي على شبكة موثوقة. قد تحتاج إلى
صلاحيات مرتفعة لإنشاء واجهة TUN. للاطلاع على حالة العقدة:

```sh
./uqdactl getSelf
./uqdactl getPeers
./uqdactl doctor
./uqdactl test 200:1234::1
```

يعرض أمر `doctor` حالة البرنامج والهوية والأقران وواجهة TUN مع خطوات مقترحة
عند وجود مشكلة، دون تغيير الإعدادات أو عرض كلمات مرور الأقران. راجع
[شرح الفحص](docs/doctor.md).

الوضع `-autoconf` يولّد هوية جديدة عند كل تشغيل. عند الانتقال من تثبيت سابق،
احتفظ بالمفتاح الخاص واتّبع [إرشادات التوافق ونقل الهوية](docs/compatibility.md).

## الأمان والتوثيق

عُقدة لا تخفي هوية المتصل ولا تغني عن حماية التطبيقات والجدار الناري. واجهة
الإدارة لا تتضمن مصادقة؛ أبقِها محلية وقيّد الوصول إليها. للإبلاغ الخاص عن ثغرة،
راجع [سياسة الأمان](SECURITY.md).
