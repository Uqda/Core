# عُقدة

[English](README.md) · [التوثيق](docs/README.md) · [الإصدارات](https://github.com/Uqda/Core/releases) · [الإبلاغ عن مشكلة](https://github.com/Uqda/Core/issues/new?template=bug_report.yml)

**عُقدة شبكة مشفّرة لأجهزتك لا تديرها أي شركة.** لا حساب تنشئه، ولا خادم تنسيق
مركزي، ولا اشتراك. يحصل كل جهاز على عنوان IPv6 دائم مشتق من مفتاحه الخاص،
وتتواصل الأجهزة عبر جلسات مشفّرة من طرف إلى طرف، سواء عبر الإنترنت أو مباشرةً
عبر شبكتك المحلية.

عُقدة (Uqda) تنفيذ مستقل الصيانة متوافق مع شبكة
[Yggdrasil](https://yggdrasil-network.github.io/) القائمة، ولا ينشئ شبكة منفصلة
ولا يمثّل تأييدًا من مطوّري المشروع الأصلي.

> **مشروع تجريبي.** عُقدة قيد التطوير النشط. تخضع لاختبارات واسعة، لكنها لم
> تخضع بعدُ لتدقيق أمني مستقل. لا تعتمد عليها حيث يعرّض تعطّلها الأشخاص أو
> الأنظمة الحساسة للخطر.

## لماذا عُقدة؟

| | عُقدة | شبكات VPN الشائعة (Tailscale وZeroTier وNetBird) |
|---|---|---|
| تحتاج حسابًا | لا | نعم |
| خادم تنسيق مركزي | لا يوجد: لا شيء يمكن إيقافه أو حجبه أو رفع سعره | مطلوب (مستضاف أو تستضيفه بنفسك) |
| تعمل على الشبكة المحلية دون إنترنت | نعم (اكتشاف محلي) | محدود |
| إضافة جهاز | `uqda invite` ثم `uqda join` (لمرة واحدة، تنتهي صلاحيتها، بلا كلمة مرور داخلها) | تسجيل الدخول لدى الشركة |
| من يصل إلى كل خدمة | جدار ناري مدمج بقواعد حسب مفتاح الجهاز | قواعد على خادم الشركة |
| مصافحة محمية من إعادة الإرسال | نعم، بين أجهزة عُقدة | نعم |
| اتصال مباشر عبر NAT | عبر عُقد وسيطة | نعم |

السطر الأخير هو ما يتفوّق فيه الآخرون حاليًا؛ راجع [خارطة الطريق](docs/roadmap.md).

## نوعان من الشبكات

- **مجموعة خاصة:** لا يتواصل معك إلا من يشاركك سرّ المجموعة. مناسبة لأجهزتك
  أو عائلتك أو فريقك، وهي الخيار الافتراضي.
- **الشبكة العامة:** تصل إلى أي عقدة على الشبكة العالمية ويصل إليك أي منها،
  ويقرّر الجدار الناري ما هو مفتوح.

يشرح دليل [الشبكات](docs/networks.md) النوعين ومتى تستخدم كلًّا منهما.

## التثبيت والتشغيل بثلاثة أوامر

ثبّت البرنامج لنظامك ([كل الخيارات](docs/installation.md)):

| النظام | التثبيت |
|---|---|
| Linux | `curl -fsSLo uqda-install.sh https://raw.githubusercontent.com/Uqda/Core/main/contrib/install/linux.sh && sudo sh uqda-install.sh install` |
| macOS | `brew install --cask Uqda/tap/uqda` |
| Windows | ملف `.msi` المناسب لجهازك من [الإصدارات](https://github.com/Uqda/Core/releases) |
| Debian / Ubuntu | ملف `.deb` من [الإصدارات](https://github.com/Uqda/Core/releases) |
| Umbrel | المتجر المجتمعي `https://github.com/Uqda/umbrel-app-store` ← **Uqda Network** |

ثم:

<div dir="ltr">

```sh
sudo uqda setup country=germany   # private network, firewall and two fast peers
sudo systemctl restart uqda       # setup prints the right command for your system
sudo uqda invite                  # on each new device: sudo uqda join <invite>
```

</div>

- الأمر الأول ينشئ شبكة خاصة ويفعّل الجدار الناري ويضيف أسرع قرينين متاحين في
  الدولة المختارة.
- الأمر الثاني يعيد تشغيل الخدمة، ويطبع `setup` الأمر المناسب لنظامك.
- الأمر الثالث يصدر دعوة. نفّذ `uqda join` بها على كل جهاز جديد.

يعرض `uqda find` الدول المتاحة. والشرح الكامل، بما فيه كيف تصل إلى خدمة على
جهاز آخر، في دليل [البدء](docs/getting-started.md).

## الأوامر اليومية

| الأمر | ماذا يفعل |
|---|---|
| `uqda status` | فحص الحالة مع طريقة إصلاح كل تحذير |
| `uqda info` | عنوانك ومفتاحك العام |
| `uqda peers` | الاتصالات المباشرة وحركة البيانات وزمن الاستجابة |
| `uqda firewall` | قواعد الجدار الناري والحزم المحجوبة |
| `uqda test ADDRESS` | اختبار الوصول وفقد الحزم إلى عقدة أخرى |
| `uqda help COMMAND` | شرح أي أمر |

## الأمان باختصار

- **الهوية:** مفاتيح Ed25519، والعنوان مشتق من المفتاح ولا يمكن انتحاله دونه.
- **الجلسات:** مشفّرة من طرف إلى طرف، تنقلها العُقد الوسيطة ولا تستطيع قراءتها.
- **المجموعات الخاصة:** يُقوّى سرّ المجموعة بخوارزمية Argon2id، ولا تستطيع العُقد
  من خارج المجموعة فتح جلسات معك.
- **الجدار الناري:** مفعّل افتراضيًا للأجهزة الجديدة، ولا يدخل إلا ما يردّ على
  اتصالاتك أو ما تسمح به من خدمات.
- **مصافحة الاتصال:** تثبت أجهزة عُقدة امتلاكها لمفاتيحها في كل اتصال، فلا يمكن
  إعادة إرسال مصافحة مسجّلة، وتُحدّ موجات الاتصالات غير المكتملة.
- **الدعوات:** محمية بـ TLS 1.3 مربوطة بمفتاح الجهاز الداعي، ولمرة واحدة،
  وتنتهي صلاحيتها، ومحدودة المحاولات.

عُقدة **لا** توفّر إخفاء الهوية، وواجهة الإدارة دون مصادقة (تبقى محلية). راجع
[نموذج الأمان](docs/security.md)، وأبلغ عن الثغرات بسرية وفق [SECURITY](SECURITY.md).

## عن المشروع

- فرعان: `main` المستقر، و`beta` الذي تصل إليه التحديثات أولًا. راجع [الفروع](docs/branching.md).
- يمرّ كل تغيير بمجموعة الاختبارات كاملة على Linux وmacOS وWindows: كشف التزامن،
  والاختبار بالمدخلات العشوائية، والحزم لكل الأنظمة، واختبار توافق مع تنفيذ
  Yggdrasil الرسمي. راجع [الاختبارات](docs/testing.md).
- المساهمات مرحّب بها: [CONTRIBUTING](CONTRIBUTING.md)، والتغييرات في [CHANGELOG](CHANGELOG.md).
